# Security Policy

## Supported Versions

Security updates are provided for the latest published release of each
`@aziontech/*` package in this repository. Please make sure you are running the
most recent version before reporting an issue.


## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them privately through one of the following channels:

- **GitHub Security Advisories** (preferred): open a private report at
  <https://github.com/aziontech/bundler/security/advisories/new>
  ([how it works](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)).
- **Email**: send the details to [security@azion.com](mailto:security@azion.com).

Please include as much detail as possible:

- A description of the vulnerability and its impact.
- Steps to reproduce (proof of concept, affected version, environment).
- Any suggested remediation, if known.

## Disclosure Process

We follow a coordinated disclosure process. We will acknowledge your report,
keep you informed while we investigate and fix it, and publish a security
advisory once a patched release is available. Please do not disclose the
vulnerability publicly until that advisory has been published.
